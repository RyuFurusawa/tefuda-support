Tefuda

あなただけの、英単語学習アプリ

Tefuda は、あなたが Google スプレッドシートに書いた単語を、そのまま単語帳として使うアプリです。 このページでは、その連携の設定手順を最初から順に説明します。 ひな形をコピーすれば、3 手順・5 分ほどで繋がります。

スプレッドシート連携は必須ではありません。 アプリの中だけで単語を追加して使うこともできますし、CSV の読み込み・書き出しにも対応しています。 シートと繋ぐと、PC で編集した内容がアプリに反映され、アプリで覚えた結果がシートへ書き戻ります。

1. ひな形をコピーする

シート名も列の見出しも Apps Script も入った、そのまま使えるひな形を用意しています。 下のボタンから自分の Google ドライブへコピーしてください。

ひな形をコピーする

開くと「スプレッドシートのコピー」という画面が出るので、コピーを作成を押します。 自分のドライブに複製され、Apps Script も一緒にコピーされます。 コピーしたファイルの名前は自由に変えて構いません。

ひな形には単語がいくつか入っています。動きを確かめたら消して、自分の単語を入れてください。 english と japanese だけ埋めれば充分です。品詞・例文・語源などの 空欄は、アプリの「空欄をまとめて埋める」でまとめて作れます。
自分で一から用意する場合（コピーを使わないとき）

すでに単語を貯めたスプレッドシートがあって、それをそのまま使いたい場合はこちらです。 シートと列は、あとから自動で作られます。Apps Script を貼って公開すれば、 初回の同期で 単語 文章 の 2 シートと必要な列が用意されます。 すでにある列や、自分で足したメモ列はそのまま残ります。

したがって最低限やることは、下のコードを貼って保存することだけです。 見出しを手で揃えたい場合のために、列の並びも載せておきます。

列の見出しを入れる

それぞれのシートの 1 行目に、次の見出しを入れます。 順番は自由で、間に自分用の列を挟んでも構いません（アプリは見出しの名前で探します）。

単語シート

english	japanese	pos	example	example_jp	example_blank	answer_display	etymology	derivatives	idioms	other_meanings	synonyms	mastery	is_active	added_date	mastered_date	last_graded

文章シート

english	japanese	section	order	mastery	is_active	added_date	mastered_date	last_graded
上のブロックはタブ区切りです。「コピー」を押してシートの A1 セルに貼り付けると、 各列に分かれて入ります。

最初は english と japanese だけ埋めれば充分です。 品詞・例文・語源などの空欄は、アプリの「空欄をまとめて埋める」で自動生成できます。

Apps Script を貼り付ける

  1. スプレッドシートのメニューから 拡張機能 → Apps Script を開きます。

  2. 最初から入っているコードをすべて消して、下のコードを貼り付けます。

  3. 保存します（⌘S）。

/**
 * 復習カード用 Apps Script Web App。
 *
 * この版で守っていること:
 *
 * 1. シートは「名前」で引く（getSheetByName）。
 *    並び順（getSheets()[0]）で引くと、タブを並べ替えただけで
 *    単語と文章が丸ごと入れ替わる。
 *
 * 2. 列は「見出し名」で対応づける（headerMap_）。
 *    位置で書くと、列を足したり並べ替えたりしたときに
 *    別の列を踏みつぶす。
 *
 * 3. 知らない列は触らない。
 *    アプリが送ってこないキーの列は、既存の値をそのまま残す。
 *    手で足したメモ列などが消えない。
 *
 * デプロイ: 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
 *   次のユーザーとして実行: 自分
 *   アクセスできるユーザー: 全員
 */

// シート名。スプレッドシート側のタブ名と一致させること。
const WORD_SHEET = '単語';
const SENTENCE_SHEET = '文章';

// アプリが読み書きする列の見出し。並び順は問わない。
const WORD_COLS = [
  'english', 'japanese', 'pos', 'example', 'example_jp', 'example_blank',
  'answer_display', 'etymology', 'derivatives', 'idioms',
  'other_meanings', 'synonyms', 'mastery', 'is_active',
  'added_date', 'mastered_date', 'last_graded',
];

const SENT_COLS = [
  'english', 'japanese', 'section', 'order', 'mastery', 'is_active',
  'added_date', 'mastered_date', 'last_graded',
];

// ---------------------------------------------------------------- 入口

function doGet() {
  return json_({
    words: readSheet_(WORD_SHEET, WORD_COLS),
    sentences: readSheet_(SENTENCE_SHEET, SENT_COLS),
  });
}

function doPost(e) {
  try {
    const payload = JSON.parse(e.postData.contents);
    if (payload.words) writeSheet_(WORD_SHEET, WORD_COLS, payload.words);
    if (payload.sentences) writeSheet_(SENTENCE_SHEET, SENT_COLS, payload.sentences);
    return json_({ ok: true });
  } catch (err) {
    return json_({ ok: false, error: String(err) });
  }
}

// ---------------------------------------------------------------- 中身

function json_(value) {
  return ContentService
    .createTextOutput(JSON.stringify(value))
    .setMimeType(ContentService.MimeType.JSON);
}

/** 名前でシートを引く。無ければ作る。順番には一切依存しない。 */
function sheet_(name, cols) {
  const book = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = book.getSheetByName(name);
  if (!sheet) {
    sheet = book.insertSheet(name);
    sheet.getRange(1, 1, 1, cols.length).setValues([cols]);
  }
  return sheet;
}

/** 見出し行から「列名 → 列番号(0始まり)」を作る。足りない見出しは末尾に足す。 */
function headerMap_(sheet, cols) {
  const width = Math.max(sheet.getLastColumn(), 1);
  const header = sheet.getRange(1, 1, 1, width).getValues()[0]
    .map(function (v) { return String(v).trim(); });

  const map = {};
  header.forEach(function (name, index) {
    if (name && !(name in map)) map[name] = index;
  });

  // アプリが使う列で、まだシートに無いものだけを末尾に追加する。
  const missing = cols.filter(function (name) { return !(name in map); });
  if (missing.length) {
    sheet.getRange(1, header.length + 1, 1, missing.length).setValues([missing]);
    missing.forEach(function (name, i) { map[name] = header.length + i; });
  }
  return map;
}

function readSheet_(name, cols) {
  const sheet = sheet_(name, cols);
  const map = headerMap_(sheet, cols);
  const rows = sheet.getLastRow() - 1;
  if (rows < 1) return [];

  const values = sheet.getRange(2, 1, rows, sheet.getLastColumn()).getValues();
  return values
    .filter(function (row) { return String(row[map['english']]).trim() !== ''; })
    .map(function (row) {
      const out = {};
      cols.forEach(function (key) {
        const at = map[key];
        out[key] = at === undefined ? '' : row[at];
      });
      return out;
    });
}

/**
 * 全置換で書く。ただし
 *  - 列は見出し名で位置を決める
 *  - アプリが送ってこない列は、同じ english の既存行から引き継ぐ
 */
function writeSheet_(name, cols, records) {
  const sheet = sheet_(name, cols);
  const map = headerMap_(sheet, cols);
  const width = sheet.getLastColumn();

  // 既存行を english で引けるようにしておく（知らない列を残すため）。
  const kept = {};
  const rows = sheet.getLastRow() - 1;
  if (rows > 0) {
    sheet.getRange(2, 1, rows, width).getValues().forEach(function (row) {
      const key = String(row[map['english']]).trim();
      if (key) kept[key] = row;
    });
  }

  const out = records.map(function (record) {
    const key = String(record['english']).trim();
    const row = kept[key] ? kept[key].slice() : new Array(width).fill('');
    while (row.length < width) row.push('');

    cols.forEach(function (col) {
      // 送られてこなかったキーは触らない（既存の値を残す）。
      if (!(col in record)) return;
      const at = map[col];
      if (at !== undefined) row[at] = record[col];
    });
    return row;
  });

  if (rows > 0) sheet.getRange(2, 1, rows, width).clearContent();
  if (out.length) sheet.getRange(2, 1, out.length, width).setValues(out);
}
このスクリプトは、シートを名前で探し、列を見出しの名前で対応づけます。 そのため、タブを並べ替えても、列を足しても、順番を変えても壊れません。 アプリが知らない列（自分用のメモ列など）は、書き戻しのときもそのまま残ります。

2. ウェブアプリとして公開する

  1. Apps Script の画面で右上の デプロイ → 新しいデプロイ を選びます。

  2. 歯車アイコンから種類に ウェブアプリ を選びます。

  3. 次のとおり設定します。

    項目選ぶもの
    次のユーザーとして実行自分
    アクセスできるユーザー全員
    「全員」を選んでも、シートが公開されるわけではありません。 公開されるのはこの窓口（URL）だけで、シート自体は非公開のままです。 ただし URL を知っている人は読み書きできます。 パスワードと同じように扱い、人に見せないでください。 アプリはこの URL を iPhone の Keychain に保存します。

  4. 初回はアクセスの承認を求められます。

    このとき 「このアプリは Google で確認されていません」 （Google hasn't verified this app）という警告が出ます。そのまま進めて構いません。 自分で用意したスクリプトを初めて承認するときに必ず出るもので、 Google の審査を通していないスクリプトはすべてこう表示されます。 アクセスするのは自分のスプレッドシートだけです。

    左下の 詳細（Advanced）→ （プロジェクト名）に移動（安全ではないページ） → 許可 と進んでください。

    この警告が出るのは自分が最初に承認するときだけです。 「自分」として実行する設定にしてあるので、アプリから同期する側には表示されません。

  5. 表示される ウェブアプリの URL をコピーします。 https://script.google.com/macros/s/……/exec という形です。

3. アプリに URL を入れる

  1. Tefuda を開き、右上の ≡ から 設定 を開きます。

  2. いちばん上の欄に、コピーした URL を貼り付けます。

  3. 接続して同期 を押します。「☁ 同期済み」と出れば成功です。

別のシートに繋ぎ替えるときは、「端末を空にしてから接続」を使ってください。 前のシートの単語が端末に残っていると、書き戻しのときに新しいシートへ流れ込みます。

5. 例文などの自動生成について

単語と訳だけ入れておけば、品詞・例文・例文の訳・語源・派生語・イディオム・他の意味・類似語を 自動で作れます。穴埋め問題もそこから組み立てられます。 一覧の「空欄をまとめて埋める」を押せば、足りない項目だけをまとめて補えます。

既定では Apple Intelligence の端末内モデルを使います。 通信は発生せず、入力した単語が端末の外へ出ることはありません。追加の費用もかかりません。 設定で Claude API に切り替えることもできます（利用者自身の API キーが必要で、語数ぶん課金されます）。

生成された内容には誤りが含まれることがあります。 とくに語源は、端末内モデルが実際とは違う説明を作ることがあります。 例文や語義も、文脈によっては不自然なことがあります。 そのまま覚え込む前に目を通し、おかしいところは一覧から直してください （行をタップすると編集できます。手で直した内容は「空欄を埋める」で上書きされません）。
端末内での生成には Apple Intelligence に対応した端末と、 設定でのオンが必要です。使えない場合は、下の「うまくいかないとき」を参照してください。

6. うまくいかないとき

「このアプリは Google で確認されていません」と出る

自分のスクリプトを初めて承認するときに必ず出る警告です。そのまま進めて構いません。 詳細（Advanced）→ （プロジェクト名）に移動 → 許可 と進んでください。一度承認すれば、以後は出ません。

ログイン画面が出る／接続できない

デプロイの「アクセスできるユーザー」が全員になっていないと、 アプリからの接続が Google のログイン画面へ回されて失敗します。 「デプロイを管理」から編集し、全員に変えたうえで、 バージョンを新バージョンにして更新してください。

「接続して同期」でエラーが出る

  • URL の末尾が /exec になっているか確認してください（/dev では動きません）
  • デプロイの「アクセスできるユーザー」が全員になっているか確認してください
  • スクリプトを直したあとは、デプロイし直す必要があります。 「デプロイを管理」から編集し、バージョンを「新バージョン」にして更新してください

「リストの順番」で並ばない

設定画面の「文章シートの order 列」を見てください。 届いていませんと出ている場合は、Apps Script の SENT_COLS に 'order' が入っているか確認してください。 列はあるが番号が空と出ている場合は、シートの order 列に番号を入れてください。

シートや列が足りない

単語 文章 のシートや、アプリが使う列が無い場合は、 同期のときに自動で作られます。手で用意する必要はありません。 すでにある列や、自分で足したメモ列は消えずに残ります。

単語と文章が入れ替わってしまった

シートを名前ではなく順番で参照する古いスクリプトを使っていると、 タブを並べ替えただけで中身が入れ替わります。このページのスクリプトに差し替えてください。 アプリ側でも入れ替わりを検知して取り込みを止めますが、 すでにシートが壊れている場合は、スプレッドシートの ファイル → 変更履歴 から壊れる前の版に戻してください。

例文の自動生成が使えない

端末内の生成には Apple Intelligence が必要です。設定 → Apple Intelligence と Siri で、 Apple Intelligence と Siri の両方をオンにしてください。 スクリーンタイムの「コンテンツとプライバシーの制限」で塞がれていることもあります。 アプリの設定画面に「端末内モデルの診断」があるので、原因の切り分けに使えます。

読み上げが鳴らない・発音が不自然

設定 → 読み上げ で、使っている音声を確認できます。 「自動の選び直し」を押すと選び直します。高品質な音声は 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語 から追加できます。
