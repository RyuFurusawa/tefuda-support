要点

Tefuda は利用者を追跡しません。広告や解析の仕組みは入っていません。 開発者がデータを受け取ることもありません。 データが端末の外へ出るのは、利用者自身が設定したときだけです。

端末の中に保存されるもの

  • 単語・文章とその学習状況（習熟度、最後に採点した日時など）
  • 出題の設定（問題数、習熟度の計算式、読み上げの音声など）
  • スプレッドシートの URL と、Anthropic の API キー — この 2 つは iOS の Keychain に保存します

これらはすべて端末内に保存されます。開発者はアクセスできません。

端末の外へ出るもの

Google スプレッドシート（利用者が設定した場合のみ）

設定画面で URL を登録すると、単語・文章とその学習状況が、 利用者自身のスプレッドシートとやり取りされます。 送り先は利用者が指定した URL のみで、開発者のサーバーは経由しません。

Anthropic（設定で Claude を選んだ場合のみ）

例文などの自動生成は、既定では端末内のモデル（Apple Intelligence）で行われ、 通信は発生しません。設定で生成方法を Claude API に切り替え、利用者自身の API キーを 登録した場合にかぎり、単語とその意味が Anthropic のサーバーへ送られます。 この場合、Anthropic のプライバシーポリシーが適用されます。

Weblio（「より詳しく」を押した場合のみ）

ボタンを押したときだけ、その単語を含む URL を Safari で開きます。

マイクと音声

発音判定と「話して答える」「話して追加」でマイクを使います。 音声の認識は端末内で完結し、録音した音声が外部へ送られることはありません。 文字起こしの結果は、上記の設定をしている場合にかぎり、 意味の判定のために端末内のモデル（または Anthropic）へ渡されます。

子どものプライバシー

本アプリは特定の年齢層を対象に個人情報を収集する設計ではありません。

変更について
